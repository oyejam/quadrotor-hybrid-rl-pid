# Models

Trained model weights (`best_model.zip` / `final_model.zip` for PPO and Hybrid) are
produced by `scripts/train_ppo.py` and `scripts/train_hybrid.py` into `results/ppo/`
and `results/hybrid/` respectively, and are git-ignored (see `.gitignore`) since they
can be regenerated by re-running training.

Once final models are trained for the report, copy the ones used to produce the
reported results here (or link to a cloud-stored copy) so results are reproducible
without re-running the full training budget. Document which config/commit produced
each file.
