# Models

Trained model weights (`best_model.zip` / `final_model.zip` for PPO and Hybrid) are
produced by `scripts/train_ppo.py` and `scripts/train_hybrid.py`, and are git-ignored
by default (see `.gitignore`) since they can be regenerated by re-running training.

**Phase 1** (`results/ppo/`, `results/hybrid/`, `results/hybrid_tight_clip/`): this
note was never acted on, and those weights were only ever local files on the
original MacBook. They were not copied here before that machine's local copy was
lost in the move to the second machine, so docs/results.md's phase 1 numbers are not
re-runnable from committed weights, only from the logged `evaluations.npz` training
curves and `results/robustness_sweep.csv` already in the repo.

**Phase 2** (`results/phase2/{ppo,hybrid}_seed{0,1,2}/`): fixed this. Each
`best_model.zip` (the checkpoint every evaluation and the demo video actually load,
~300KB each) is committed directly, carved out of the `*.zip` ignore rule in
`.gitignore`. `final_model.zip` (the end-of-training checkpoint, not used anywhere)
stays git-ignored and regeneratable by re-running training. This means every number
in docs/results_phase2.md and the demo video can be reproduced, or re-evaluated
under a different sweep, without retraining.

Committing the weights is a convenience, not the only path to them: the exact
commands in README.md's "Running and Usage" section (`train_ppo.py` /
`train_hybrid.py` with `--seed`/`--output-dir`/`--total-timesteps`) independently
regenerate a working `best_model.zip` from scratch. Verified by re-running both
commands at a reduced timestep count into a scratch directory -- both produced a
`best_model.zip` that loads via `PPO.load()` and predicts a valid 4-dim RPM action,
the same way every evaluation script and the demo video load these files. Exact
bit-for-bit reproduction isn't guaranteed (fixed seeds don't pin subprocess
scheduling across `n_envs: 16` parallel workers), but the documented commands are
confirmed to produce a working, loadable policy, not just assumed to.
