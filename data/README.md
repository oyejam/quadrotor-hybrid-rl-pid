# Data

This project does not use an external dataset — all "data" is generated by running the
PyBullet quadrotor simulation (`gym-pybullet-drones`). Nothing needs to be downloaded
here.

Artifacts produced by training/evaluation runs (trajectories, logs, CSVs) are written to
`results/` and are git-ignored except for small summary CSVs used directly in the report
(document which ones here once they exist).
